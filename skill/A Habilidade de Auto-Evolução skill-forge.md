# Processo de Evolução
1. Leia o `learnings.md` para identificar o padrão de sucesso mais recente.
2. Crie uma nova pasta em `.claude/skills/` com o nome da nova função.
3. Gere um arquivo `SKILL.md` com YAML frontmatter e instruções de execução.
4. Teste a nova skill e atualize o `AGENTS.md` para incluí-la no catálogo.
